# Scheduling calendar comparison

The development-only `/podglad-kalendarzy` page preserves all eleven interactive
concepts for client review. Keep the alternatives until the final design is approved.
Each concept links to its research source; all use live, read-only DEV availability.
The page includes a print layout for saving the comparison as PDF.

Variant 11 is the current choice. It renders the same `AvailabilityCalendarClient`
and shared UI calendar as the homepage team section, so subsequent refinements stay
consistent. The other ten concepts remain comparison prototypes.

The comparison page is unavailable in production builds and is excluded from indexing.
