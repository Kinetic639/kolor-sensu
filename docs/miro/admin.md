## Admin · 1. Newsletter

Ramka `3458764688427579169` · [w Miro](https://miro.com/app/board/uXjVEaKfAoo=/?moveToWidget=3458764688427579169)

Wydania, wysyłka, archiwum i adresy w portalu admina.

| Kartka                                  | Kolor   | Co ma się dziać                                                                                                                                                                                                                                                                                        | Czym sprawdzone                                                                                                                      |
| --------------------------------------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| 1. Lista wydań                          | żółty   | Zakładając: admin otwiera Newsletter → Wydania / Gdy: przegląda listę / Wtedy: widzi szkice na górze, potem wydania zaplanowane i wysłane: temat, numer, stan (szkic, zaplanowane, wysyłane, wysłane), kiedy i do ilu osób; „Nowe wydanie”                                                             | Stan i opis wydania: test widoku; kolejność listy: test bazy; sama lista w portalu bez testu → żółty                                 |
| 2. Nowe wydanie i szkic                 | żółty   | Zakładając: admin klika „Nowe wydanie” / Gdy: wpisuje temat, zajawkę, wstęp i zakończenie, dodaje karty i zapisuje / Wtedy: szkic jest zapisany i można do niego wrócić; bez tematu nie da się go wysłać, a portal mówi, czego brakuje                                                                 | Zasady szkicu i „czego brakuje”: test kontraktu; zapis szkicu: test bazy; formularz w portalu bez testu → żółty                      |
| 3. Karty artykułów i e-booków           | żółty   | Zakładając: w Edukacji są opublikowane artykuły i e-booki / Gdy: admin dodaje karty, zmienia ich kolejność albo dodaje własną kartę z linkiem / Wtedy: wydanie ma karty w tej kolejności (najwyżej 12); własna karta ma tytuł, opis i bezpieczny link; wycofany artykuł nie trafia do e-maila          | Karty (limit, linki, pomijanie wycofanych) i przesuwanie: testy kontraktu, e-maila i widoku; edytor kart w portalu bez testu → żółty |
| 4. Podgląd e-maila                      | żółty   | Zakładając: szkic ma treść / Gdy: admin klika „Podgląd wydania” / Wtedy: widzi wydanie tak, jak przyjdzie do skrzynki: temat, zajawkę, treść i link do wypisania                                                                                                                                       | Treść HTML i tekstowa z linkiem do wypisania: testy e-maila; podgląd w portalu (zapytanie do strony) bez testu → żółty               |
| 5. Wysyłka testowa na swój adres        | żółty   | Zakładając: admin chce zobaczyć wydanie u siebie / Gdy: klika „Wydanie na Twój adres e-mail” / Wtedy: dostaje wydanie na adres, na który się loguje, bez linku do wypisania; lista zapisanych nic nie dostaje                                                                                          | E-mail testowy bez linku do wypisania: test e-maila; wysyłka testowa ze strony bez testu → żółty                                     |
| 6. Wyślij teraz albo zaplanuj           | zielony | Zakładając: szkic jest gotowy / Gdy: admin klika „Wyślij teraz” albo wybiera dzień i godzinę i „Zaplanuj wysyłkę” / Wtedy: wydanie dostaje kolejny numer i idzie do wszystkich zapisanych (potwierdzonych) przez Resend, teraz albo o wybranej godzinie czasu polskiego; godzina w przeszłości: odmowa | Testy wysyłki (Resend, planowanie, odmowy, numer) i bazy; godzina w czasie polskim: test widoku → zielony                            |
| 7. Wycofanie zaplanowanej wysyłki       | zielony | Zakładając: wydanie jest zaplanowane / Gdy: admin wycofuje wysyłkę przed czasem / Wtedy: wysyłka jest odwołana w Resend, a wydanie wraca do szkiców; wydania, które już wyszło, nie da się wycofać                                                                                                     | Testy wycofania (Resend odwołuje albo nie, już wysłane) i bazy → zielony                                                             |
| 8. Gdy Resend odmówi                    | zielony | Zakładając: Resend nie przyjmuje wydania / Gdy: admin wysyła / Wtedy: wydanie wraca jako szkic, nic nie wychodzi, a portal mówi po polsku, co się stało                                                                                                                                                | Test wysyłki i bazy (szkic wraca bez zmian); komunikaty z kontraktu → zielony                                                        |
| 9. Archiwum na stronie                  | zielony | Zakładając: wydanie wyszło / Gdy: admin zostawia je w archiwum albo z niego zdejmuje / Wtedy: w archiwum na stronie są tylko wysłane wydania zostawione w archiwum; zdjęte znika ze strony                                                                                                             | Test bazy (archiwum tylko z wysłanych i zostawionych) i strony archiwum → zielony                                                    |
| 10. Usunięcie szkicu, wysłane bez zmian | zielony | Zakładając: admin ma szkic albo wysłane wydanie / Gdy: usuwa szkic albo próbuje zmienić wysłane / Wtedy: szkic znika po potwierdzeniu; wysłanego nie da się już zmienić ani usunąć                                                                                                                     | Test bazy (usunięcie szkicu, wysłane bez edycji) → zielony                                                                           |
| 11. Lista adresów                       | żółty   | Zakładając: admin otwiera Newsletter → Adresy / Gdy: przegląda listę / Wtedy: widzi adresy ze stanem (czeka na potwierdzenie, zapisany, wypisany, odbity), skąd się zapisały i liczby w zakładkach                                                                                                     | Liczenie stanów: test kontraktu; lista tylko dla admina: test bazy; lista w portalu bez testu → żółty                                |
| 12. Zgoda adresu                        | żółty   | Zakładając: ktoś prosi o informację o swoich danych / Gdy: admin otwiera „Zgoda” przy adresie / Wtedy: widzi treść zgody, wersję i datę, z którą adres się zapisał                                                                                                                                     | Zapis zgody z wersją: test bazy; okno „Zgoda” w portalu bez testu → żółty                                                            |
| 13. Usunięcie adresu                    | zielony | Zakładając: ktoś prosi o usunięcie danych / Gdy: admin usuwa adres z listy / Wtedy: adres znika z listy od razu, a z Resend przy najbliższej synchronizacji (do 10 minut); usunięcie danych klienta usuwa też jego adres                                                                               | Testy bazy i synchronizacji z Resend → zielony                                                                                       |
| 14. Eksport adresów                     | żółty   | Zakładając: admin chce mieć listę u siebie / Gdy: pobiera eksport CSV / Wtedy: dostaje plik tylko z zapisanymi adresami, poprawnie zapisany dla Excela                                                                                                                                                 | Treść pliku: test kontraktu; pobieranie z portalu (tylko admin) bez testu → żółty                                                    |
| 15. Tylko admin                         | zielony | Zakładając: specjalista albo gość / Gdy: próbuje wejść w Newsletter albo wywołać jego funkcje / Wtedy: portal admina go nie wpuszcza (strona braku dostępu), a baza odmawia zapisu, wysyłki i listy adresów                                                                                            | Testy bazy (odmowa dla specjalisty i gościa) → zielony                                                                               |
| 16. Zapis na stronie w CMS              | zielony | Zakładając: admin w CMS włącza albo wyłącza blok newslettera na stronie głównej / Gdy: publikuje stronę / Wtedy: blok zapisu pokazuje się albo znika ze strony głównej, pod artykułami i w archiwum                                                                                                    | Test bazy i strony głównej (blok ukryty do publikacji) → zielony                                                                     |
| 17. Testy end-to-end                    | różowy  | Zakładając: wydanie testowe na DEV / Gdy: test pisze wydanie, robi podgląd i wysyłkę testową, planuje i wycofuje wysyłkę, przegląda adresy / Wtedy: testy przechodzą na DEV i STAGING bez wysyłki do zapisanych                                                                                        | Nie zrobione → różowy                                                                                                                |
